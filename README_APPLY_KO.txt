TimeGate 앱 업데이트 적용 방법

1. GitHub Desktop에서 JangsuBatteryPilot_v0.6 저장소를 선택합니다.
2. Repository > Show in Explorer를 눌러 현재 저장소 폴더를 엽니다.
3. 이 ZIP의 모든 파일을 그 폴더에 그대로 풀고, 같은 파일이 있으면 덮어쓰기 합니다.
4. APPLY_APP_UPDATE.bat 를 한 번 실행합니다.
5. GitHub Desktop으로 돌아가 변경 파일이 표시되는지 확인합니다.
6. Summary 예: TimeGate v0.34.79 START+FINISH policy
7. Commit to main > Push origin

주의: 앱 ZIP을 RiderControlCenter 저장소 안에 넣으면 안 됩니다. 앱은 JangsuBatteryPilot_v0.6 저장소에만 적용합니다.
