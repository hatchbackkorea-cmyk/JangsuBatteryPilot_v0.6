# Jangsu Battery Pilot v0.6.0 — Natural Voice Copilot

AMFLOW PL 800Wh + 장수 280랠리 스테이지1용 오프라인 배터리 코파일럿입니다.

## 핵심 기능
- GPS를 GPX 트랙에 매칭하여 현재 코스 km 표시
- 1~135km 예상 배터리 및 충전 계획 표시
- 실제 배터리 음성 입력 후 소비율 자동 학습/재예측
- 종점 목표 잔량 기준 여유/주의/위험 판단
- 다음 10km 획고와 다음 주요 업힐 분석
- 화면이 꺼져도 GPS/한국어 TTS 안내 유지
- 50km/75km 동일 장소의 진행도 오인식 방지
- 충전 타이머/충전속도 학습
- 주행 리포트 및 재시작 복원

## v0.6.0 자연어 음성 코파일럿
큰 마이크 버튼을 누르고 명령어를 외울 필요 없이 평소 말투로 말할 수 있습니다. 자연어 해석은 앱 안에서 오프라인 규칙 기반으로 처리되며, 별도 AI 서버 연결이 필요하지 않습니다.

### 실제 배터리
- `배터리가 지금 48프로 남았어`
- `지금 48이야`
- `마흔여덟 프로 남았네`

### 충전
- `70까지 충전했어`
- `충전 끝, 70프로`
- `충전 시작해`
- `충전 다 했어`

### 질문
- `보급소까지 얼마나 남았어?`
- `끝까지 얼마나 남았지?`
- `이대로 가도 돼?`
- `배터리 충분해?`
- `앞에 힘든 업힐 있어?`
- `지금 어디쯤이야?`
- `얼마나 남았어?`

### 안내 설정
- `조용히 해`
- `기본 안내로 해`
- `더 자주 알려줘`
- `명령어 어떻게 말해?`

### 목표 잔량
- `종점에서 15프로 남기고 싶어`
- `종점 목표 15프로`

숫자는 `48`, `사십팔`, `마흔여덟` 같은 표현을 지원합니다.
