# GPX Battery Copilot v0.29.1
## v0.29.1 주행 HUD 고도 프로필 집중화
- 주행 첫 화면의 `누적 에너지 비교` 카드를 제거하고 피드백 페이지로 이동. 실제 누적 / 우리 예측 / Avinox 비교 계산은 그대로 유지.
- 주행 고도 카드에서 테스트 스위치와 GPX 위치 슬라이더를 제거하고 설정 페이지의 `주행 / 충전 테스트` 영역으로 이동.
- 주행 HUD의 속도 / 종점 ETA / 10km 고도 / 10km 후 배터리 4개 보조 안내칩을 화면에서 제거. 내부 계산은 호환성을 위해 유지.
- 확보된 공간으로 실시간 고도 프로필을 50dp → 178dp로 확대하고 일반 프로필 모드로 표시해 코스 형상을 더 크게 확인.
- v0.29.0 우천 GPS 보호, v0.28.9 상황기반 학습, 증분 배포/서명/설치 경로는 그대로 유지.

## v0.29.0 우천/불량 GPS 점프 방어
- 계획주행에서 정확도 60m 초과 위치는 코스 진행도/학습 로그에 반영하지 않습니다.
- 연속 위치 사이 물리적으로 불가능한 GPS 점프를 차단합니다.
- GPS가 켜져 있을 때는 계획/주행 서비스에 NETWORK 위치를 섞지 않고 GPS_PROVIDER만 사용합니다.
- 잘못된 진행거리로 고정된 경우, 실제 코스의 다른 위치가 3회 연속 안정적으로 확인되면 자동 복구합니다.
- 불량 GPS 동안에는 마지막 신뢰 위치를 유지해 SOC/모드 데이터가 수십 km 앞 구간으로 오염되는 것을 막습니다.

## v0.28.9 Avinox 원본 상황기반 v2 재해석
- 기존에 내부 저장된 Avinox `.proto`를 다시 해석해 `경사 + 속도 + Rider Power + Cadence + 실제 Assist 모드 + SOC 소비`가 묶인 별도 v2 학습을 만듭니다.
- v1 평균 소비학습은 그대로 보존하고, 2페이지 모드별 주행전략만 v2를 우선 사용합니다.
- v0.28.9 설치 후 내부에 원본이 남아 있으면 v2 스키마 전환을 자동으로 한 번 재해석하며, `설정 → 학습 관리 · 원본 A+ / FIT 백업 → 기존 Avinox 원본 전부 재해석`에서 수동 재구축할 수 있습니다.
- v2 표본이 부족한 GPX 블록은 기존 v1 값으로만 보조하고 화면에 `※`/fallback 안내를 남깁니다.

## v0.28.8 변경 파일만 모바일 배포
- 모바일 배포가 원격 `main`의 Git tree와 새 ZIP의 Git blob SHA-1을 비교합니다.
- 내용과 실행권한이 동일한 파일은 GitHub blob 업로드를 생략하고, 실제 변경/추가 파일만 전송합니다.
- ZIP에서 사라진 기존 소스 파일은 이전처럼 원격에서도 삭제하며 `.github/workflows`는 기본 OFF 정책대로 보존합니다.
- 배포 로그에 `변경 업로드 / 동일 건너뜀 / 삭제` 개수를 표시해 실제 전송량을 바로 확인할 수 있습니다.
- 변경 파일이 0개여도 같은 tree로 새 release commit을 만들 수 있어 기존 auto-release workflow 흐름을 유지합니다.

## v0.28.7 완성된 APK 재설치 오류 수정
- 백그라운드 원클릭 배포가 다운로드한 APK는 `files/release_apk/`에 보관됩니다.
- FileProvider에 해당 내부 경로를 추가하여 배포 직후 팝업뿐 아니라 나중에 `완성된 APK 설치` 버튼을 눌러도 Android 설치 화면이 정상 열립니다.
- 최신버전 업데이트 경로와 배포 직후 cache 설치 경로는 그대로 유지합니다.


## v0.28.6 충전 포인트 정차/출발 시각
- 2페이지 `모드별 주행 전략`의 충전 포인트 셀을 `도착시각 / 도착SOC→목표SOC / 정차시간 / 출발시각` 4줄로 표시합니다.
- 모드별 예상 도착 SOC가 다르면 같은 목표 SOC라도 필요한 정차시간과 출발시각이 각각 달라집니다.
- 현재 실제 충전 중이면 남은 충전시간을 사용합니다.


## v0.28.5 모드별 주행 전략 테이블
- 코스 2페이지의 기존 세로 `포인트별 예상 도착시각`을 ECO / AUTO / TRAIL / TURBO 4열 전략 테이블로 변경했습니다.
- 각 포인트에서 `도착시각 + 예상 SOC`를 같은 칸에 표시하고, 충전지점은 `도착 SOC → 계획 충전 SOC`를 함께 보여줍니다.
- 맨 아래 `전체 남은 전략` 행에서 모드별 총 소요시간, 남은 충전 정차시간, 종점 SOC를 한눈에 비교합니다.
- 네 열은 모두 Avinox 외부 예상 소비량 숫자가 아니라 **우리 GPX + 모드별 개인학습 모델**로 독립 계산합니다. Avinox에서 선택한 비교 모드는 해당 열을 강조하는 용도로만 사용합니다.
- 실제 자전거에서 AUTO로 기록된 구간은 AUTO 학습, ECO/TRAIL/TURBO로 기록된 구간은 각각 해당 모드 학습에 남아 미래의 비슷한 지형 전략 추론에 사용됩니다.
- 모드별 시간은 Avinox 원본 A+ / 기존 검증 A급의 실제 모드별 속도 학습을 우선합니다. 모드 속도 표본이 부족하면 현재 이동평균/전체 학습을 시간 보조값으로 사용하고 표에 `※`를 표시합니다.
- Avinox 원본 `.proto` A+ 자동동기화가 계속 주 학습 경로이며 FIT 단독은 기존처럼 B급 백업/호환 경로로 유지합니다.

## v0.28.4 비교 모드에 맞춘 자체 SOC 예측
- Avinox 비교에서 ECO/AUTO/TRAIL/TURBO를 선택하면 테스트/계획의 자체 예측도 같은 모드의 검증 학습 bucket을 사용합니다.

## v0.28.3 긴급충전 카카오맵 자전거 길안내 연동
- 긴급충전 후보를 확정하면 Battery Copilot이 비상 우회 세션/복귀 앵커를 먼저 저장한 뒤 카카오맵 공식 `kakaomap://route` 스킴을 `by=bicycle`로 호출합니다.
- 카카오맵이 전면에 떠도 RideService 포그라운드 GPS/BLE/SOC/주행 로그는 계속 동작합니다. Battery Copilot 알림을 누르면 즉시 앱으로 복귀할 수 있습니다.
- 카카오맵 앱이 없거나 앱 스킴 실행이 실패하면 Kakao REST 자전거 경로의 `landingUrl`, 그것도 없으면 모바일웹 자전거 길찾기로 자동 폴백합니다.
- 비상충전 완료 입력 시 RETURN 단계로 전환하고 원래 GPX 이탈점까지 카카오맵 자전거 복귀 길찾기를 자동으로 다시 엽니다.
- OUTBOUND/RETURN 중 앱으로 돌아와도 비상 패널의 카카오 자전거 안내 버튼으로 경로를 다시 열 수 있습니다.
- 공식 URL 스킴은 자전거 길찾기 화면까지 연결합니다. 카카오맵 버전/설정에 따라 실제 음성 `안내 시작`은 카카오맵 화면에서 마지막 1회 탭이 필요할 수 있습니다.

## v0.28.2 SOC 연동 페이스 체인
- 배터리 예측/충전/도달선 엔진은 그대로 두고 주행 어시스트 목표값 계산만 정리했습니다.
- 계산 순서를 `SOC 여유 + 실시간 소비보정 → 권장속도 → 라이더/모터 분담 → 권장 케이던스 → 권장기어`로 연결했습니다.
- 예상보다 배터리가 빨리 소모되거나 다음 목표 SOC가 부족하면 권장속도와 모터 목표를 낮추고 라이더 분담과 케이던스를 완만하게 높입니다.
- 권장기어는 현재 속도가 목표 범위를 벗어난 경우 목표 속도 범위 안의 속도를 기준으로 계산하여 `속도는 줄이세요`와 `무거운 기어`가 동시에 제시되는 충돌을 줄였습니다.
- SRAM 실제 기어/실시간 모터파워·케이던스를 읽는 기능은 아니며, 검증된 A+ 학습값과 현재 속도/SOC를 이용한 목표값입니다.

## v0.27.5 이중 도달선 + 단계별 주행 경고
- 파란 `안전 도달선`을 항상 표시합니다. 현재 SOC에서 설정된 안전 기준 잔량(기본 15%)을 남기고 갈 수 있는 GPX 한계입니다.
- 충전 임박/ECO 연결/긴급충전/하드리저브 구간에서는 빨간 `하드 도달선`을 함께 표시합니다. 기본 하드 리저브는 7%입니다.
- 다음 충전소 기준 여유거리를 `안전 +4.8km / 하드 +8.2km`처럼 숫자로 함께 표시합니다. 음수면 해당 기준으로 충전소에 닿지 못한다는 뜻입니다.
- 충전 임박/ECO 연결은 상단 주황 경고 배너가 짧게 강조됩니다. 긴급충전은 빨간 배너 + 약한 페이지 플래시 + 진동, 하드 리저브 진입은 더 강한 짧은 페이지 플래시 + 진동을 사용합니다.
- 경고는 계속 깜빡이지 않고 단계가 바뀌거나 새 충전 지점에 접근할 때만 짧게 강조됩니다. 충전 중에는 주행 경고를 숨깁니다.
- 테스트 모드는 전체 GPX를 유지하면서 동일한 파란/빨간 도달선과 경고 로직을 화면에서 검증할 수 있으며 진동은 발생시키지 않습니다.

# GPX Battery Copilot v0.26.5

## v0.26.5 충전계획 포함 ETA
- 모든 ETA는 목표 포인트까지의 주행시간뿐 아니라 그 전에 예정된 미완료 충전시간을 누적합니다.
- 현재 충전 중이면 BLE SOC 기준 남은 충전시간만 반영하고, 이미 완료한 충전은 제외합니다.
- 충전소는 도착시각과 계획 충전 완료 후 예상 출발시각을 함께 표시합니다.

- 현재 주행의 이동평균 속도를 우선 사용해 ETA 변동을 줄입니다.
- 다음 포인트 요약에도 거리 + ETA를 함께 표시합니다.
- v0.26.3의 고정 서명 GitHub Release 자동 업데이트 구조를 그대로 유지합니다.

# GPX Battery Copilot v0.22.1

## v0.22.1 계획/권장 분리 + A/B 학습
### 충전 계획과 앱 권장
- **내 충전 계획**: 사용자가 각 충전소에 직접 정한 충전 목표 %. 계획주행 충전 알림은 이 값에서 울린다.
- **앱 권장**: 다음 충전소(없으면 종점)에 `충전권장 기준 잔량`을 남길 수 있도록 현재 충전소에서 필요한 최소 SOC를 계산한 값.
- 앱 권장은 내 계획을 바꾸지 않고, 내 계획도 앱 권장을 덮어쓰지 않는다.
- 충전 상태에서도 `내 계획`과 `앱 권장`을 동시에 표시한다.

- A급: Avinox FIT + 앱 ZIP 검증 페어로 배터리 SOC/모드 소비까지 정식 학습.
- B급: Avinox FIT 단독 여러 개를 선택해 거리·고도·속도·Rider/Motor Power·Cadence만 보조학습. 배터리 소비계수는 수정하지 않음.
- 설정의 `종점 목표 잔량`을 `충전 권장 기준`으로 표시하고, 계획주행 충전지점의 앱 권장 SOC와 알림 목표를 이 기준으로 역산.
- 충전 목표 도달 시 알림/진동/음성만 제공하며 충전은 계속되고, 100%에서 한 번 더 알림.

## Avinox BLE 실험실
- 설정 → `Avinox BLE 진단 시작`
- 주변 BLE 장치를 검색하고 자전거로 의심되는 장치를 눌러 GATT 연결
- Avinox 앱/계기판의 현재 배터리 %를 입력하고 `현재 값과 대조`
- 배터리가 1~2% 변한 뒤 같은 절차를 다시 하면 움직이는 Characteristic 후보를 좁힐 수 있음
- `BLE 진단 로그 저장` 파일을 분석용으로 내보낼 수 있음
- 이 기능의 데이터는 검증 전까지 개인 학습과 예측에 0% 반영
- Avinox 앱이 자전거 BLE 연결을 독점하는 경우: 현재 배터리 % 확인 → Avinox 앱 완전 종료 → BLE 실험실에서 검색

오프라인 우선 GPX 라이딩 배터리 코파일럿입니다. 장수280은 내장 예비 코스일 뿐이며, 사용자가 불러와 선택한 **어떤 GPX 코스든** 저장된 개인 학습 데이터를 적용해 배터리 예측과 어시스트를 계산합니다.

## v0.15.0 핵심

- Avinox 전원 OFF/절전으로 FIT가 여러 개 생겨도 `FIT 여러 개 가져오기`에서 한 번에 선택해 하나의 실제 라이딩 세션으로 결합
- 여러 FIT을 시간순으로 정렬하고 위치 연속성, 시간 공백, 기록 겹침을 자동 검사
- 파일 사이 휴식/전원 OFF 시간은 이동시간·평속·파워 에너지 학습에서 제외
- 결합된 모든 원본 FIT과 `session_manifest.csv`, `session_gaps.csv`를 보존
- 코스 페이지에서 `현재 코스`를 바로 탭해 전체 GPX 선택
- 코스 페이지에서 `+ GPX 불러오기`를 바로 실행하고, 불러온 GPX를 즉시 현재 코스로 선택
- 선택된 GPX의 거리/고도/충전 계획 + 개인 학습 데이터를 기반으로 BatteryPlan 재구성
- 장수280 Stage1은 삭제하지 않고 **기본 예비 코스**로만 유지
- 주행 메인 정보 카드를 2열로 재배치
  - 1행: 배터리 판단 / 실제 배터리
  - 2행: 다음 지점 / 다음 업힐
- 같은 화면 높이에서 핵심 숫자와 문자를 더 크게 표시
- 좌우 스와이프 5페이지 순서를 `주행 → 코스 → 설정 → 학습 → 피드백`으로 변경하고 앱 실행 첫 화면을 실시간 주행 대시보드로 고정
- 설정 페이지에서 음성 안내, 화면 유지, 거리/시간 안내 간격, 종점 목표, 테스트 모드를 직접 조작
- 학습 페이지에서 FIT/GPX 학습을 바로 시작하고 현재 학습 상태와 초기화 기능 제공
- FIT/GPX 상세 배터리 체크포인트 입력과 저장 기록 관리는 기존 Historical Ride 화면을 재사용


## v0.15.0 Free Ride / 사후 3자 비교

- 첫 화면의 `주행 시작`에서 **계획주행 / 임의주행** 선택
- 임의주행은 현재 선택된 GPX와 완전히 독립적으로 동작
- 휴대폰 GPS로 실제 거리·고도·속도를 기록하고 주행 중 음성 배터리 입력을 시간/거리와 함께 저장
- 출발 직후 첫 배터리 입력을 기준으로 중간 충전을 포함한 실제 누적 소비량 계산
- 충전 시작/완료 기록을 유지해 배터리가 다시 채워져도 누적 소비량이 끊기지 않음
- 임의주행 종료 시 실제 GPS 트랙을 GPX/CSV/JSON/ZIP으로 저장
- 종료 후 Avinox FIT 파일을 최근 주행에 연결 가능
- FIT 연결 시 **현재 개인모델의 학습 전 사후예측값**을 먼저 저장해 비교 공정성 유지
- 종료 후 Avinox ECO/AUTO/TRAIL/TURBO 전체 소비량을 100% 초과값까지 별도 입력 가능
- `실제 누적 소비 ↔ 우리 모델(FIT 기준·학습 전) ↔ Avinox 선택 모드` 오차 비교
- Avinox 예상값은 학습에 절대 사용하지 않음
- FIT을 연결한 임의주행은 사용자가 선택할 때만 실제 배터리 체크포인트를 개인 학습에 반영

## v0.14.0 Avinox Independent Benchmark + 누적 에너지 비교

Avinox 앱의 ECO / AUTO / TRAIL / TURBO **전체 코스 예상 소비량**은 코스별 외부 benchmark로만 보존합니다. 100% 초과값도 그대로 저장하며, 예를 들어 254%는 배터리 2.54팩 분량입니다.

- Avinox 데이터는 BatteryPlan, 개인 학습, 충전소 도착 예측에 **0% 반영**
- 선택 모드는 `예측 적용 모드`가 아니라 **실시간 화면에서 비교할 Avinox 모드**
- 실제 누적 소비량은 `시작 100% + 누적 충전량 - 현재 실제 잔량`으로 계산해 중간 충전 뒤에도 비교 연속성 유지
- 주행 1페이지에서 `실제 누적 / 우리 실시간 보정 모델 / Avinox`를 동시에 표시
- Avinox 현재구간 값은 자체 GPX 에너지 분포를 모양(shape)으로만 사용해 전체 Avinox 소비량을 현재 위치까지 환산
- 자체 모델 종점 누적 예상과 Avinox 전체 예상도 함께 표시
- 개인 학습 데이터 초기화와 Avinox benchmark 삭제는 서로 독립

예: Avinox AUTO 254%, 실제 누적 118%, 자체 실시간 모델 112%라면 주행 중 세 값을 바로 비교할 수 있습니다. 충전으로 배터리가 20%→70%가 되어도 누적 충전 +50%를 기록하므로 실제 누적 소비량 비교는 끊기지 않습니다.
