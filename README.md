# GPX Battery Copilot v0.11.0

오프라인 우선 GPX 라이딩 배터리 코파일럿입니다. v0.11.0은 **Battery Model 2.0 + Data Integrity**를 시작하는 버전으로, 장수280에 미리 넣어 둔 배터리 학습값 없이 중립 모델에서 학습을 시작합니다.

## v0.11.0 핵심

- 첫 실행 시 기존 개인/과거 배터리 학습 데이터만 1회 초기화하고 학습 0개에서 시작
- 장수280 Stage1 코스 자체와 설정/주행 로그는 유지
- 장수280 내장 배터리 마커는 예측/학습에 사용하지 않음
- 중립 초기식 + 실제 FIT/GPX/주행 데이터로 개인화
- 일반 배터리 음성 입력은 직전 RIDING 입력 후 10초 이내 재입력 시 직전 값을 무효화하고 **새 입력 시점의 km/시간**으로 교체
- 충전은 하나의 `충전 시작 ↔ 충전 완료` 버튼으로 기록
- 충전 전/후 배터리는 `확인 / 취소`로 확정하고 같은 코스 km에 저장
- 주행 화면의 핵심 숫자 확대 및 세로 중앙 배치
- 좌우 스와이프 4페이지: `지도/코스 ← 주행 → 설정/정보 → 피드백`
- 코스 메뉴의 기본 Stage1 중복 카드 제거: 상단 현재 코스 박스를 탭해 코스 선택

## Avinox FIT 활용

FIT 분석 결과 화면은 **거리 / 획득고도 / 손실고도 / 이동시간 / 평속**만 표시합니다.

내부 학습/재분석을 위해 FIT에 존재하는 다음 시계열은 보존합니다.

- 시간, GPS, 누적거리, 고도, 속도
- 케이던스
- 라이더 파워
- 모터 파워

심박은 v0.11.0에서 읽기/저장/학습 대상으로 사용하지 않습니다.

Avinox처럼 모터 파워가 충분히 기록된 FIT에서는 실제 배터리 체크포인트 사이의 소비량을 0.5km 블록에 배분할 때 **모터 출력 에너지 분포 75% + 중립 지형식 25%**를 사용합니다. motor_power를 배터리 입력전력과 1:1로 간주하지 않으며, 파워가 없거나 결측이면 중립 지형식만 사용합니다.

## 데이터 무결성

FIT/GPX 시계열은 정상/업힐/급업힐/무동력 다운힐/코스팅/정차/센서 결측/이상치 상태를 구분할 수 있도록 저장합니다. `motor_power=0`만으로 다운힐을 단정하지 않고 이동·지속시간/거리·고도하강을 함께 확인합니다.

가져온 FIT/GPX는 원본 파일, `telemetry.csv`, 실제 배터리 체크포인트 `battery_events.csv`를 앱 내부에 보존하여 이후 지도+고도 그래프 피드백 기능에서 다시 분석할 수 있게 합니다.

## 피드백 페이지

v0.11.0의 피드백 페이지는 데이터 보존 기반과 최근 주행 리포트를 제공합니다. Google 지도와 거리/고도 그래프의 양방향 슬라이드 동기화, 배터리 소모 강도별 경로 색상, 무동력 다운힐 파란색 표시는 후속 UI에서 저장된 원본/시계열을 사용해 연결할 예정입니다.
