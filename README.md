# GPX Battery Copilot v0.10.1

GPX 코스를 기반으로 주행 진행, 배터리 예측, 충전 계획, 음성 안내, 로그 저장과 개인 소비 학습을 수행하는 Android 앱입니다.

## v0.10.1 — Historical Ride Build Fix
- 과거 라이딩 중간 배터리 목록의 삭제 버튼에서 발생한 Kotlin 변수명 충돌 수정

## v0.10.0 — 과거 라이딩 학습
설정 → 배터리 학습 데이터 → `과거 라이딩 학습 가져오기 (FIT / GPX)`에서 앱 제작 이전의 실제 라이딩도 학습에 사용할 수 있습니다.

### FIT (권장)
- 거리 / GPS / 고도 / 기록 시간 / 속도
- 심박 / 케이던스 / 파워가 FIT Record에 있으면 자동 추출
- Garmin 공식 FIT Java SDK를 Maven Central 의존성으로 사용

### GPX
- 거리 / GPS / 고도
- `<time>`이 있으면 주행시간 계산
- GPX 확장에 심박/케이던스/파워가 있으면 함께 읽음

### 배터리 입력
- 시작 배터리 + 종료 배터리, 또는 총 사용 배터리 %
- 중간 배터리 지점 추가 가능
- 중간 충전은 같은 km에 `도착 잔량 → 충전 후 잔량` 순서로 두 번 추가
- 최종 확인 후 `학습에 사용`을 눌러야 반영

### 학습 안전장치
- SHA-256 파일 해시로 동일 기록 중복 학습 방지
- 학습된 과거 라이딩별 개별 삭제 가능
- 설정의 전체 학습 초기화로 개인 학습을 다시 시작 가능
- 원본 FIT/GPX 파일은 앱이 영구 보관하지 않고 분석 결과/학습값만 저장

## 배터리 학습의 핵심
배터리 예측은 기본적으로 거리 + 상승고도 + 경사 분포 + 실제 배터리 소비량을 사용합니다. FIT의 심박/케이던스/파워는 분석 메타데이터로 함께 저장하지만, 미래 코스의 라이더 노력값을 알 수 없으므로 현재 예측식의 직접 입력값으로 강제 사용하지 않습니다.
