# GPX Battery Copilot v0.8.0 — Ride UI Refactor

AMFLOW PL 800Wh를 중심으로 만든 오프라인 GPX 라이딩 배터리 코파일럿입니다. 임의 GPX를 불러오면 거리·고도·업힐·배터리 예측·GPS 진행도·주행 로그를 해당 코스를 기준으로 처리합니다.

## v0.8.0 핵심 변화
- 메인 화면을 실제 주행 정보 중심으로 단순화
- 상단 `코스` 메뉴에서 GPX 불러오기 / 저장 코스 선택 / 삭제
- 상단 `설정` 메뉴에서 음성안내 / 안내간격 / 화면 항상 켜기 / 종점 목표 잔량 / 테스트 모드 관리
- 종점 목표 잔량 `1% ~ 99%`
- 음성 안내 수준 3단계 제거
- 거리 기준 자동안내 `0~50 km` (`0`은 끄기)
- 시간 기준 자동안내 `0~120분` (`0`은 끄기)
- 거리/시간 기준을 둘 다 켜면 먼저 도달한 기준으로 한 번 안내하고 두 기준을 함께 재시작
- 충전 타이머 삭제
- 충전 후 실제 배터리 입력(`70까지 충전했어`)은 새 소비 기준점으로 계속 사용
- 자연어 `5킬로마다 알려줘`, `10분마다 알려줘`, `종점 목표 20` 지원

## 코스 메뉴
- 휴대폰 파일 선택기로 `.gpx` 불러오기
- 여러 GPX 코스 저장 및 선택
- 사용자 GPX 삭제
- 기본 장수280 Stage1 코스는 삭제 방지
- GPX의 `<trkpt>` / `<rtept>` / `<ele>` / waypoint 분석
- 주행 중에는 코스 변경/삭제/불러오기 차단

## 설정 메뉴
- 자동 음성 안내 켜기/끄기
- km 단위 안내 간격
- 분 단위 안내 간격
- 화면 항상 켜기
- 종점 목표 잔량 1~99%
- 테스트 모드 및 테스트 코스 위치 슬라이더
- 진행 위치 / 실제 배터리 보정 초기화
- 실제 주행 기록 중에는 테스트 모드 변경 차단

## 배터리 예측
개인 학습 데이터가 없을 때는 장수280 실제 측정 구간을 기반으로 한 기본 모델을 사용합니다.
- 평지 기준 약 `0.65 % / km`
- 상승고도 약 `0.035 % / m`

실제 주행 중 `배터리 48`, `지금 48프로야`, `70까지 충전했어`처럼 말하면 현재 코스 km에 실제 잔량을 저장하고 이후 예측을 즉시 보정합니다.

## 자연어 Voice Copilot 예시
- `배터리가 지금 48프로 남았어`
- `70까지 충전했어`
- `종점 목표 20프로`
- `5킬로마다 알려줘`
- `10분마다 알려줘`
- `거리 안내 꺼`
- `보급소까지 얼마나 남았어?`
- `앞에 힘든 업힐 있어?`
- `이대로 가도 돼?`
- `여기를 보급소로 등록해`

자연어 해석은 인터넷 LLM을 호출하지 않고 앱 내부 규칙 기반으로 처리됩니다.

## 주행 로그
주행 종료 시 다음 파일을 생성합니다.
- `*.gpx`: 실제 GPS 이동궤적
- `*.csv`: 시간/위도/경도/GPS고도/속도/코스km/이탈거리/예상배터리/실제배터리
- `*.json`: 코스 정보, 배터리 입력, 보급/코스이탈 이벤트, 요약
- `*.zip`: 위 파일 묶음

주행 중에는 로그를 계속 append하여 앱이 종료되더라도 진행 세션을 복구할 수 있도록 설계되어 있습니다.
