# GPX Battery Copilot v0.10.2

GPX 코스를 기반으로 주행 진행, 배터리 예측, 충전 계획, 음성 안내, 로그 저장과 개인 소비 학습을 수행하는 Android 앱입니다.


## v0.10.2 — Ride Stats Accuracy Fix
과거 FIT/GPX 학습 파일의 분석 기준을 정확도 우선으로 다시 작성했습니다.

- 표시 항목: **거리 / 획득고도 / 손실고도 / 이동시간 / 평속**
- FIT: Garmin FIT Session/Lap에 저장된 공식 합계값을 최우선 사용
- GPX: GPS 트랙 거리, GPX 고도, 타임스탬프로 직접 계산
- 심박 / 케이던스 / 파워는 분석 결과에서 제거
- 같은 파일을 예전 버전에서 학습했어도 다시 불러와 새 분석값으로 교체 가능

## v0.10.1 — Historical Ride Build Fix
- 과거 라이딩 중간 배터리 목록의 삭제 버튼에서 발생한 Kotlin 변수명 충돌 수정

## v0.10.0 — 과거 라이딩 학습
설정 → 배터리 학습 데이터 → `과거 라이딩 학습 가져오기 (FIT / GPX)`에서 앱 제작 이전의 실제 라이딩도 학습에 사용할 수 있습니다.

### FIT (권장)
- 거리 / 이동시간 / 평속 / 획득고도 / 손실고도
- Session/Lap 공식 통계를 우선 사용하고 Record 트랙은 보조로 사용
- Garmin 공식 FIT Java SDK를 Maven Central 의존성으로 사용

### GPX
- GPS 트랙 기반 거리 / 획득고도 / 손실고도
- `<time>`이 있으면 이동시간과 평속 계산

### 배터리 입력
- 시작 배터리 + 종료 배터리, 또는 총 사용 배터리 %
- 중간 배터리 지점 추가 가능
- 중간 충전은 같은 km에 `도착 잔량 → 충전 후 잔량` 순서로 두 번 추가
- 최종 확인 후 `학습에 사용`을 눌러야 반영

### 학습 안전장치
- SHA-256 파일 해시로 동일 기록 중복 학습 방지
- 학습된 과거 라이딩별 개별 삭제 가능
- 설정의 전체 학습 초기화로 개인 학습을 다시 시작 가능
- 원본 FIT/GPX 파일은 앱이 영구 보관하지 않고 분석 결과/학습값만 저장

## 배터리 학습의 핵심
배터리 예측은 기본적으로 거리 + 상승고도 + 경사 분포 + 실제 배터리 소비량을 사용합니다. 과거 파일 학습은 거리 + 상승고도 + 경사 분포 + 실제 배터리 소비량을 핵심 데이터로 사용합니다.
