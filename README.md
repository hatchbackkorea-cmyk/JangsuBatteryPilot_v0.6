# GPX Battery Copilot v0.7.0 — GPX Ride Copilot

AMFLOW PL 800Wh를 중심으로 만든 오프라인 GPX 라이딩 배터리 코파일럿입니다. v0.7.0부터는 장수280 전용 앱이 아니라, 사용자가 휴대폰에서 임의의 GPX를 불러오면 그 코스를 기준으로 거리·고도·업힐·배터리 예측·주행 로그 기록이 동작합니다.

## v0.7.0 핵심 변화
- 휴대폰 파일 선택기로 `.gpx` 코스 불러오기
- 여러 GPX 코스를 앱 내부에 저장하고 선택/삭제
- 기본 장수280 Stage1 GPX는 계속 내장
- `<trkpt>`가 없으면 `<rtept>`도 코스로 사용
- GPX에서 총거리, 누적상승/하강, 고도 프로필, 다음 10km 획고, 주요 업힐을 자동 분석
- GPX waypoint를 일반 POI 및 보급/충전 후보로 자동 활용
- 음성 `여기를 보급소로 등록해`로 현재 진행 km에 사용자 보급 지점 추가
- GPX 거리 + 상승량 기반 범용 배터리 예측
- 완료 라이딩의 실제 배터리 입력을 다음 라이딩 예측에 학습
- 주행 중 실제 배터리 음성 입력을 이용한 실시간 소비율 재보정
- 주행 중 GPS 로그를 약 2.5초 간격으로 계속 append하여 앱이 종료되어도 진행 세션 복구 가능
- 주행 종료 시 실제 이동궤적 GPX, 상세 CSV, 세션 JSON, 세 파일을 묶은 ZIP 자동 생성
- 최근 로그 ZIP을 Android 저장 위치로 내보내기

## 기본 배터리 모델
개인 학습 데이터가 없을 때는 장수280 실제 측정 구간을 바탕으로 한 기본값을 사용합니다.
- 평지 기준: 약 `0.65 % / km`
- 상승고도: 약 `0.035 % / m`

예: 25km + 상승 735m라면 기본 모델 소비량은 약 42%입니다. 실제 라이딩에서 배터리 값을 여러 번 입력하면 지형 구간별 보정계수를 누적 학습하여 다음 GPX 예측에 반영합니다.

## 자연어 Voice Copilot 예시
- `배터리가 지금 48프로 남았어`
- `70까지 충전했어`
- `보급소까지 얼마나 남았어?`
- `앞에 힘든 업힐 있어?`
- `이대로 가도 돼?`
- `종점에서 15프로 남기고 싶어`
- `주행 시작`
- `주행 종료`
- `여기를 보급소로 등록해`
- `이 코스 정보 알려줘`

자연어 해석은 인터넷 LLM을 호출하지 않고 앱 내부 규칙 기반으로 처리됩니다.

## 주행 로그
주행 종료 시 앱 전용 Documents 영역의 `GPXBatteryCopilot/RideLogs` 폴더에 다음 파일을 생성합니다.
- `*.gpx`: 실제 GPS 이동궤적
- `*.csv`: 시간/위도/경도/GPS고도/속도/코스km/이탈거리/예상배터리/실제배터리
- `*.json`: 코스 정보, 배터리 입력, 충전/보급/코스이탈 이벤트, 요약
- `*.zip`: 위 3개 파일 묶음

앱의 `최근 주행 로그 ZIP 내보내기` 버튼으로 사용자가 원하는 Android 폴더에 복사할 수 있습니다.

## GPX 고도 데이터가 없는 경우
GPX에 `<ele>` 데이터가 충분하지 않으면 거리/GPS 진행도/로그/거리 기반 배터리 기능은 동작하지만, 누적상승·주요 업힐 분석은 `고도 데이터 없음`으로 표시합니다.
