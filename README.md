# GPX Battery Copilot v0.9.0 — GPX Charging Planner

AMFLOW PL 800Wh를 중심으로 만든 오프라인 GPX 라이딩 배터리 코파일럿입니다. 임의 GPX를 불러오면 거리·고도·업힐·배터리 예측·GPS 진행도·주행 로그를 해당 코스를 기준으로 처리합니다.

## v0.9.0 핵심 변화
- GPX 웨이포인트를 충전소 후보로 추출하고 원하는 지점만 체크해서 사용
- 웨이포인트가 없어도 주소 검색 / 코스 km / 고도 프로필 / 현재 진행 위치로 충전소 추가
- 주소 검색 결과를 GPX 최근접 코스 km로 자동 연결하고 코스 이격거리 표시
- 충전소별 충전 후 목표 배터리와 추가 우회거리를 저장
- 배터리 판단 박스는 `다음 충전소`를 우선 목표로 사용하고, 마지막 충전소를 지나면 자동으로 `종점` 기준으로 전환
- 충전소가 없으면 종점 기준을 유지하고 필요 시 자동 권장 충전 km를 제안
- v0.8.1의 컴팩트 주행 화면과 v0.8.0 설정 체계는 그대로 유지

## 코스 메뉴
- 휴대폰 파일 선택기로 `.gpx` 불러오기
- 여러 GPX 코스 저장 및 선택 / 사용자 GPX 삭제
- GPX `<wpt>` 웨이포인트에서 충전소 선택
- 충전소를 주소 검색 / 코스 km / 고도 프로필 / 현재 진행 위치로 직접 추가
- 충전소별 이름, 충전 후 목표 %, 추가 우회거리 수정
- 충전소가 없을 때 자동 충전 계획 분석 및 권장 km 제안
- 최근 완료한 주행 로그 ZIP 내보내기
- 기본 장수280 Stage1 코스는 삭제 방지
- 주행 중에는 코스와 충전 계획 변경 차단

## 설정 메뉴
- 자동 음성 안내 켜기/끄기
- km 단위 안내 간격
- 분 단위 안내 간격
- 화면 항상 켜기
- 종점 목표 잔량 1~99%
- 테스트 모드 및 테스트 코스 위치 슬라이더
- 진행 위치 / 실제 배터리 보정 초기화
- 실제 주행 기록 중에는 테스트 모드 변경 차단

## 배터리 예측
개인 학습 데이터가 없을 때는 장수280 실제 측정 구간을 기반으로 한 기본 모델을 사용합니다.
- 평지 기준 약 `0.65 % / km`
- 상승고도 약 `0.035 % / m`

실제 주행 중 `배터리 48`, `지금 48프로야`, `70까지 충전했어`처럼 말하면 현재 코스 km에 실제 잔량을 저장하고 이후 예측을 즉시 보정합니다.

## 자연어 Voice Copilot 예시
- `배터리가 지금 48프로 남았어`
- `70까지 충전했어`
- `종점 목표 20프로`
- `5킬로마다 알려줘`
- `10분마다 알려줘`
- `거리 안내 꺼`
- `보급소까지 얼마나 남았어?`
- `앞에 힘든 업힐 있어?`
- `이대로 가도 돼?`
- `여기를 보급소로 등록해`

자연어 해석은 인터넷 LLM을 호출하지 않고 앱 내부 규칙 기반으로 처리됩니다.

## 주행 로그
주행 종료 시 다음 파일을 생성합니다.
- `*.gpx`: 실제 GPS 이동궤적
- `*.csv`: 시간/위도/경도/GPS고도/속도/코스km/이탈거리/예상배터리/실제배터리
- `*.json`: 코스 정보, 배터리 입력, 보급/코스이탈 이벤트, 요약
- `*.zip`: 위 파일 묶음

주행 중에는 로그를 계속 append하여 앱이 종료되더라도 진행 세션을 복구할 수 있도록 설계되어 있습니다.
