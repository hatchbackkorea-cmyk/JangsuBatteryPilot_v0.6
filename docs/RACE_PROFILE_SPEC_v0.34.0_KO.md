# RACE 프로필 원칙 v0.34.0

RACE 참가자에게 요구하는 공개 프로필 입력은 딱 두 가지입니다.

- 이름
- 닉네임

전화번호, 이메일, 성별, 생년, 동호회, 자전거 정보 등은 RACE 참가를 위해 요구하지 않습니다.

앱 내부에서는 중복 전송 방지와 참가자 세션 연결을 위해 사용자에게 보이지 않는 로컬 식별자를 별도로 사용할 수 있습니다. 대회 서버의 participant_id/run_id 역시 내부 처리용이며 공개 프로필 입력 항목을 늘리지 않습니다.

중계/순위 기본 표시는 닉네임을 우선하고, 필요할 때 `닉네임 (이름)` 형태로 구분합니다.
