# TimeGate v0.34.44 live rank behavior

Participant live timing screen:
- BEST: persistent event-session best lap number + finish time.
- PREVIOUS: immediately previous lap number + finish time.
- CURRENT: current lap number + live elapsed time.
- DELTA: continuous same-position comparison against the immediately previous lap.
- LEADER: current event leader finish time/name, live leader gap, and estimated rank.

Lap history:
- LAPS / BEST LAP / OPTIMAL LAP summary.
- Full / Delta / Start lap list.
- CP sector detail table with fastest blue, slowest red, plus optimal theoretical lap.
